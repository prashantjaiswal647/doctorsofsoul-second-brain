## 1. Budget Discipline & Testing Window
- **Daily Ad Spend:** Strictly **₹100 / day** (Total allocation).
- **Mandatory Discovery Window:** **7 to 10 Days Minimum**.
  - Claude Code or any automation is **FORBIDDEN** from increasing or changing the budget during the first 7–10 days.
  - The objective of these 7–10 days is pure data collection, audience discovery, and creative angle testing.
- **Budget Scaling Gate:**
  - Any budget increase will ONLY be considered **after day 10**, post-analysis of real conversion rates, CPC, and checkout drop-offs.

## 3. Downside Protection: "Audit Before Kill" Protocol
- **Trigger:** Cumulative spend reaches **₹100 with 0 sales**.
- **Action:** **DO NOT BLIND-KILL**.
  1. Inspect **Link CTR**: If CTR >= 1.5% and CPC <= ₹4, traffic is cheap and interested. Check landing page text and Razorpay checkout friction.
  2. Inspect **Hook**: If CTR < 1.0%, tweak the headline/image text in [[ad_copy_angles]].
  3. Hard Stop: Only pause if spend crosses ₹200 with 0 conversions after creative revision.
